# PPT视觉分析笔记

## PPT1 汇报PPT (64页, 16:9)
- 封面包含清华大学深圳研究院logo（紫色）、华北电力大学logo（蓝红色）等多个高校/机构logo
- 主色调：深红(#C00000)、深灰(#3F3F3F)、黑色(#000000)、蓝色(#2E75B5)、深蓝(#03379F)
- 主要字体：微软雅黑(804次)、Arial(569次)、Times New Roman(352次)
- 主要字号：14pt(441)、16pt(292)、20pt(267)、12pt(163)、22pt(145)
- 页面结构：封面(标题幻灯片) -> 目录(节标题) -> 内容页(标题和内容) -> 节标题过渡页 -> 结束页
- 节标题页使用了group shapes (6个组合)，形成装饰性过渡效果
- 内容页大量使用图片+文本框组合

## PPT2 环境与生态 (40页, 16:9)
- 主色调：深红(#C00000)、深蓝(#002060)、紫色(#7030A0)、黄色(#FFFF00)、蓝色(#2E75B5)
- 主要字体：微软雅黑(487次)、Times New Roman(50次)、Arial(46次)
- 主要字号：24pt(146)、20pt(138)、16pt(99)、14pt(72)
- 使用自定义布局名称：目标内容与科学问题、研究队伍与工作基础、立项依据与研究现状、技术路线与创新思路
- 封面有6张图片，包含水利相关背景图
- 过渡页使用2_标题幻灯片布局

## PPT3 京津冀水网答辩 (34页, 16:9)
- 主色调：深红(#C00000)、深蓝(#002060)、紫色(#7030A0)、深灰(#3F3F3F)、黄色(#FFFF00)
- 与PPT2使用相同的模板系统（布局名称一致）
- 主要字体：微软雅黑(338次)、Times New Roman(63次)、Arial(27次)
- 主要字号：20pt(114)、24pt(89)、16pt(66)

## PPT4 自主运行水网 (84页, 16:9)
- 封面使用南水北调运河航拍图作为背景
- 主色调：深红(#C00000)、蓝色(#0F62AD)、紫色(#7030A0)、红色(#FF0000)、蓝色(#2E75B5)
- 主要字体：微软雅黑(822次)、Arial(207次)、Times New Roman(52次)
- 主要字号：28pt(475)、20pt(325)、16pt(231)、14pt(209)
- 大量使用标题幻灯片布局(38次)作为过渡页
- 369张图片，图片密度最高

## PPT5 流域水库群 (36页, 4:3)
- 唯一使用4:3比例(10x7.5 inches)的PPT
- 主色调：深红(#C00000)、黑色(#000000)、深蓝(#034A90)、白色(#FFFFFF)
- 主要字体：Times New Roman(110次)、微软雅黑(106次)、Arial(80次)
- 使用竖排标题与文本布局作为章节过渡页(9次)
- 封面图片包含水利工程相关图片

## PPT6 智慧水利团队 (94页, 16:9)
- 封面使用大型水库大坝航拍图
- 主色调：黄色(#FFFF00)、深红(#C00000)、红色(#FF0000)、蓝色(#105EAC)
- 主要字体：微软雅黑(1396次)、Times New Roman(90次)、Arial(38次)
- 主要字号：14pt(309)、32pt(236)、20pt(215)、16pt(201)
- 页数最多(94页)，使用2_标题和内容布局(81次)
- 图片密度较高(215张)

## 共性特征总结
1. 配色：深红(#C00000)是所有PPT的核心强调色，蓝色系(#002060/#0F62AD/#2E75B5/#034A90/#105EAC)为主色
2. 字体：微软雅黑为主要中文字体，Times New Roman和Arial为英文字体
3. 比例：5个PPT使用16:9，1个使用4:3
4. 风格：学术/科研汇报风格，图文并茂，大量使用示意图和照片
5. 结构：封面->目录/过渡->内容->结束，使用节标题页作为章节分隔
